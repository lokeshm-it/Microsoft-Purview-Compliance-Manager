# Regulation Reference — ISO/IEC 27001:2013

## Summary

The International Organization for Standardization (ISO) 27001 standard provides requirements for establishing, implementing, maintaining, and continuously improving an **Information Security Management System (ISMS)**. Internal and external parties use this international standard to assess an organization's ability to meet its own information security requirements. Within Compliance Manager, this regulation appears as an overarching template under the **Sub-Service Compliance Readiness** grouping of the Regulations catalog.

## Using This Regulation in Compliance Manager

1. From **Compliance Manager → Regulations**, locate **ISO/IEC 27001:2013** under **Sub-Service Compliance Readiness**
2. Review **All controls** to understand the full 233-control scope before creating a dedicated assessment
3. Review **All actions → Your actions** to identify organization-owned remediation work
4. Review **All actions → Microsoft actions** to confirm the 347 actions Microsoft has already addressed on Azure
5. If pursuing certification or a surveillance audit, create a formal assessment against this regulation from the **Assessments** page to enable test-status tracking, evidence attachment, and reporting at the individual control level

## Certification Readiness Notes

- This view provides a Microsoft 365/Azure-contextualized starting point for ISO/IEC 27001 readiness, but does **not** replace the formal ISMS documentation required by the standard — a Statement of Applicability (SoA), risk assessment methodology, and internal audit program must still be maintained independently
- Control families should be reviewed against the organization's actual SoA to confirm scope alignment (not every organization will find all 233 controls applicable, depending on exclusions justified in their SoA)
- The 2013 revision is referenced in this tenant's catalog; organizations pursuing certification should confirm with their certification body whether the current ISO/IEC 27001:2022 revision is required, and check the Compliance Manager Regulations catalog for an updated template if so
