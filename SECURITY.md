# Security Policy

## Purpose of This Repository

This repository is a **documentation and portfolio project** describing the configuration and operational use of Microsoft Purview Compliance Manager within a Microsoft 365 tenant. It contains no application code, credentials, connection strings, or executable artifacts.

## Handling of Sensitive Information

All screenshots and data referenced in this repository have been reviewed to ensure they do not expose:

- Tenant identifiers, domain names, or organization names
- User principal names, email addresses, or personal data
- API keys, client secrets, certificates, or authentication tokens
- Internal network topology or IP addressing

Compliance scores, point values, and improvement action counts shown throughout this documentation are illustrative of a representative implementation and are used solely to demonstrate the Compliance Manager workflow.

## Reporting a Security Concern

If you identify content in this repository that inadvertently exposes sensitive configuration data, tenant-identifying information, or any other security-relevant detail, please report it privately rather than opening a public issue:

1. Do **not** open a public GitHub issue describing the exposure
2. Contact the repository maintainer directly through the profile associated with this repository
3. Provide the file, line, or screenshot reference and a description of the concern

Reports will be reviewed and addressed as a priority, with affected content removed or redacted promptly.

## Scope

This policy covers the documentation, diagrams, and screenshots contained in this repository. It does not cover the Microsoft Purview Compliance Manager product itself — security issues in Microsoft 365 or Microsoft Purview should be reported directly to Microsoft via the [Microsoft Security Response Center (MSRC)](https://msrc.microsoft.com/).
