## LinkedIn Project Description

**Microsoft Purview Compliance Manager — Enterprise Compliance Assessment & Remediation Program**

Completed an end-to-end implementation of Microsoft Purview Compliance Manager, standing up a measurable, risk-based compliance program across a Microsoft 365 tenant.

The project covered the full compliance lifecycle: activating Data Protection Baseline and AI Baseline assessments, triaging a 500-item improvement action backlog by risk impact, evaluating a 391-template regulation catalog, and mapping the full ISO/IEC 27001:2013 control set — 233 Annex A controls and 347 Microsoft/Azure Control Framework actions — for ISMS certification readiness.

Key outcomes:
✅ Established a 59% baseline compliance score with a clear, risk-prioritized remediation roadmap
✅ Structured the customer-managed vs. Microsoft-managed control split to focus remediation effort where it matters most
✅ Built a repeatable governance model — ownership, testing cadence, and evidence collection — for sustaining compliance beyond initial deployment
✅ Produced enterprise-grade documentation covering architecture, implementation, ISO/IEC 27001 mapping, and audit reporting

This project reflects how compliance is actually operated inside a mature Microsoft 365 environment: not a one-time checklist, but a continuously monitored, risk-weighted program with defensible evidence behind every control.

Full documentation, architecture diagrams, and implementation guide available in the linked GitHub repository.
