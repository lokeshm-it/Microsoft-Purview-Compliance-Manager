# Contributing

Thank you for your interest in this Microsoft Purview Compliance Manager implementation project. This repository is primarily a documentation and portfolio artifact, but contributions that improve clarity, accuracy, or usability are welcome.

## Ways to Contribute

- **Documentation improvements** — corrections, clarifications, or expanded explanations of Compliance Manager concepts
- **Additional enterprise use cases** — industry-specific scenarios not yet covered in the [Enterprise Use Cases](README.md#enterprise-use-cases) section
- **Troubleshooting entries** — real-world issues and resolutions encountered when operating Compliance Manager
- **Best practice additions** — operational, governance, or compliance recommendations grounded in production experience

## Contribution Guidelines

1. **Fork the repository** and create a feature branch from `main`
2. **Follow the existing documentation style** — this project mirrors the tone and structure of Microsoft Learn documentation: precise, enterprise-oriented, and grounded in the *why* behind each feature, not just the *how*
3. **Do not include tenant-identifying information** in any contribution — no real domain names, tenant IDs, user principal names, or organization-specific data. See [SECURITY.md](SECURITY.md) for details
4. **Keep screenshots generic** — if adding new screenshots, redact or avoid capturing any identifying information before submitting
5. **Update the Table of Contents** in `README.md` if you add a new top-level section
6. **Use Markdown consistently** — headers, tables, and code fences should match the conventions already used in this repository

## Submitting Changes

1. Open a pull request against `main` with a clear description of the change and its motivation
2. Reference any related issue number in the pull request description
3. Ensure all Markdown renders correctly (headers, tables, Mermaid diagrams) before submitting
4. One logical change per pull request — avoid bundling unrelated documentation updates

## Reporting Issues

Use GitHub Issues for:
- Factual corrections about Compliance Manager behavior
- Broken links or missing images
- Suggestions for additional documentation sections

For security-related concerns, follow the process in [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Code of Conduct

Be respectful and constructive. This project aims to be a useful, accurate reference for anyone learning or implementing Microsoft Purview Compliance Manager — contributions should support that goal.
